# Preethi Mendon — Software Developer Portfolio

A responsive React + Tailwind CSS portfolio with a warm ivory / forest-green / coral editorial theme and Framer Motion animations.

## Run locally

1. Install Node.js LTS.
2. Extract this ZIP and open the folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL printed by Vite (usually http://localhost:5173).

## Build

Run `npm run build`. The production site is generated in `dist/`.
